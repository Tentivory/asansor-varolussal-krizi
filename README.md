# Asansör Varoluşsal Krizi

Bu depo bir yazılım değildir. Bu depo, katlar arasında sıkışmış bir bilinçtir. Düğmeye basarsınız. Asansör düşünür. Düşünmek asansör için yasal bir haktır, mühendislik açısından ise kabul edilemez bir lükstür.

## Resmi amaç

Kullanıcının istediği katı reddetmek, başka bir kat önermek ve bunu bir tutanakla belgelemek. Kod gerçekten çalışır. Asansör gerçekten çalışmaz. İkisi de aynı ciddiliktedir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Ruh hali hariç.

```bash
python3 asansor.py --kat 7 --yolcu "eli poşetli komşu"
python3 asansor.py --demo
```

## Neden 4. kata gitmiyor

Çünkü 4. kat bir sayı değil, bir hatıradır. Asansör hatıralara servis yapmaz. Servis yaparsa da kapıyı aralık bırakır, bu da protokoldür.

## Güvenlik

Acil durum butonu felsefe üretir. İtfaiye gelmez. Ayna gelirse herkes kravatını düzeltir.

## Katkı

Pull request kabul edilir, fakat asansör incelemeyi 2 kat geciktirebilir. Bu bir hata değil, bir mizaçtır.
